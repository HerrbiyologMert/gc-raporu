# GC Report

A small Python program that reads DNA sequences from a text file, calculates the GC content of each sequence and writes the results to a report file.

## What it does

- Reads sequences from `dizi.txt` (one sequence per line)
- Calculates the GC content (%) of each sequence
- Writes the results to `rapor.txt`
- Shows a clear message if `dizi.txt` is not found

## How to run

```
python tag15.py
```

## Example output

```
ATGCAT 33.3
CCGAA 60.0
GGGCCC 100.0
```
